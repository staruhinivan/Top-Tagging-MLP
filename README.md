# Top-Tagging-MLP

В этом репозитории реализована MLP модель для решения задачи top tagging.
Проект реализован на языке PyTorch, версия для CPU.
Архитектура модели, которая содержится в файле [model.py](./model.py), представляет собой 6 Fully Connected Layers.
Функция активации является периодической синусообразной. Ее период можно указать в файле [top_tagging_net.py](./top_tagging_net.py) в разделе "ACTIVATION FUNCTIONS", в строке periods=[0.4] (в этом случае период функции активации = 0.4). Если указать несколько чисел в массиве periods, то обучение будет проходить для каждого отдельно.
В файле [top_tagging_net.py](./top_tagging_net.py) в разделе "ПАРАМЕТРЫ" можно указать параметры. 
Самые важные из них: 

    num_epoches - число эпох
    
    neurons_lay - число нейронов в каждом уровне
    
    data_size - число массивов входных тренировочных данных из датасета
    
    val_size - число массивов для validation
    
    batch_size - размер батча
    
    load_model - загружать ли результат предыдущего обучения; можно указать True, если ранее сохранили модель
    
    save_model - сохранять ли модель после обучения
    
    N - сколько раз прогнать обучение для статистики
    

  В результате программа сохранит график зависимости Loss, validation and train accuracy от эпохи для каждой заданной функции активации (по умолчанию - периодическая функция с периодом 0.4).
  Датасет (нормированный), содержащийся в папке [Few_dataset_cut](./Few_dataset_cut), есть малая часть всего датасета, доступного по [ссылке](https://drive.google.com/file/d/1DkgVHfV8KDX5pgMfJ4Ycz-niCFkWzsxp/view?usp=drive_link)
